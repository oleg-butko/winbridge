# Tauri shell

`src-tauri` — отдельный Cargo package/lockfile, не член основного workspace. Shell читает `winbridge-desktop.local.json` рядом со своим exe, вычисляет локальный worker endpoint и предоставляет command `worker_rpc`. Конфиг содержит `schemaVersion: 1` и `workerConfigPath`; относительный путь отсчитывается от папки конфигурации. [Образец](../../examples/desktop.config.json), [подготовка Windows](../../docs/windows-validation.md). Ошибка конфигурации видна в UI. Desktop не владеет tasks/process handles и не запускает worker автоматически; закрытие окна оставляет принятые задачи работающими.

`load_command_drafts`/`save_command_draft` сохраняют форму в `winbridge-desktop-state.local.json` рядом с exe через core store. Scope: worker instance ID/project ID/workspace root; не более 128 последних draft scopes и 1 MiB всего. DTO экспортируются из protocol в TS. Закрытие main window ждёт save ACK; `core:window:allow-destroy` разрешает завершить только окно companion после записи. Восстановление формы не вызывает submit. При ошибке сохранения окно остаётся открытым с объяснением и кнопкой «Закрыть без сохранения».

UI находится в `../../ui`, production build — `../../web-dist`. Из root: `npm run build:desktop`; для dev сначала `npm run dev:ui`, затем `npm run dev:desktop`. Tray/attention появятся на этапе 5. [Windows native shell gate пройден](../../docs/windows-gate-2026-10-05.md) на host пользователя. Linux Cargo check доступен; Windows cross-target desktop check в Debian требует отсутствующий здесь `llvm-rc`. Сохранение формы и dev:ui дополнительно подтверждены пользователем на Windows; короткий сценарий остаётся в Windows инструкции для повторных прогонов.
