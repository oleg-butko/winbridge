# Этап 6: delta от проверенного поколения

Выбор пользователя 2026-10-09: ранее импортированный snapshot служит локальным
кэшем. Новый пакет содержит полный состав целевого Git commit, ZIP только новых
или изменённых файлов и ссылку на базовое поколение с SHA-256 его manifest.

Формат 1 остаётся полным пакетом. Формат 2 содержит `delta`: `snapshotId`,
`manifestSha256` базы и пары `path` / `basePath` для переиспользуемых файлов.
Пути проверяются теми же Windows правилами; пары уникальны и входят в целевой
manifest. ID delta вычисляется из commit и точной базы, отдельно от полного ID.
Publisher читает реальные Git blobs и проверяет hashes даже при переиспользовании.

Worker проверяет metadata базы, копирует нужные файлы с проверкой размера/SHA-256
в новый staging, распаковывает оставшиеся и проверяет всё целевое дерево. Только
после этого публикуется immutable generation. Hard links и изменения базы не
используются. Удалённые в Git файлы отсутствуют в новом поколении; старое остаётся.
Уже готовое целевое поколение проверяется независимо от доступности базы/shared.

Недоступная/повреждённая база — явная ошибка с предложением полного импорта.
Автоматического fallback, перезапуска build, удаления поколений или очистки кэша
нет. Новый RPC `import_delta_snapshot` требует capability `workspace_delta`;
старый worker продолжает обслуживать полный формат и не получает delta-запросы.
При обновлении пары controller обновляется прежде нового worker.

UI показывает базовый ID/hash, число переиспользуемых файлов, объём ZIP и полного
дерева, фазу копирования базы и факт проверки. Неизвестный ACK повторяется с теми
же параметрами и методом.

Проверки: изменение/rename/delete/empty files/mode, цепочка delta, неправильный
pin, повреждённая/отсутствующая база, traversal/links/extra ZIP entries,
отмена до публикации, повтор импорта без базы и отсутствие изменений базы.
Автоматический Windows gate собирает тесты в отдельном runtime через установленный
worker; desktop и новые окна не нужны. Сравнение full/delta сохраняет реальные
байты и timings; уменьшение передачи не выдаётся за ускорение всей сборки.
