## Код и независимый контроль

- Rust case: `apps/update/tests/activation_lifetime_migration.rs`, общий
  `support/retained_activation_migration.rs`. Старые19→20/20→21 profiles остаются
  fixed; SDK22 отказывается их выполнять до reference/file effects.
- PS: `test-update-lifetime-migration.ps1` выбирает schema22 профиль общего
  `test-update-journal-migration.ps1`. Локальный build cache получает exclusive
  lease, проверяется≥6GiB; old config/runtime/Windows directories не очищаются.
- Python: runner/readonly verifier используют фиксированную profile table;
  reference helper `update-activation-lifetime-migration-proof.py` сначала читает
  actual Main26 evidence. Новые результаты разбираются без duplicate JSON keys,
  floats/NaN/Infinity, с отдельным запретом выдуманных lifetime permissions.
- Exact test selection и24 намеренных подмен proof проверяются независимо от
  exit0/готового report. Всего16 Python tests, из них7 новых; они
  не подменяют native evidence.

Review также добавил повторный SHA ZIP **после локального Copy и до Expand** в
общем runner. Совпадение shared файла до Copy не гарантирует bytes локальной
копии при потере/изменении mount. Это исправление действует для всех3 profiles.

## Выполнение

Нужен установленный worker; desktop закрыт/не требуется. Новых сетевых EXE,
controller ports, UI или применения нового runtime нет. Слот runtime-test-204
в этом copy-only сценарии не заменяется. Cargo работает offline в прежнем
local test-build-cache с lease. После terminal нужно independent reread;
при неизвестном ACK/timeout наблюдать прежний task/key, не отправлять новый.

```bash
python3 scripts/run-update-lifetime-migration-native.py \
  --source-archive <clean-producer22-with-built-ui.zip> \
  --reference-source-archive /mnt/hgfs/shared/WinBridge/sources/winbridge-20261028T152129Z-d288b0f-f099744d.zip \
  --reference-target-archive /mnt/hgfs/shared/WinBridge/sources/winbridge-20261028T094607Z-b149eed-a3228347.zip \
  --reference-run-info .winbridge/update-preparation/main26-204-20261028-152239-0a6abd07/run-info.json \
  --cache-run 20261017-061527-f4639971 \
  --controller-config .winbridge/controller-snapshot.local.json
```

Потом `verify-update-lifetime-migration-native.py` с `--run-info` нового run,
`--source-archive` того же producer и обоими `--reference-*-archive` выше.

`WinBridge/source-archives`, что не меняет их basename/SHA pin; не генерировать
заново отсутствующий исторический ZIP и не менять hash ради reread.
