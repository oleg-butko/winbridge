## Причина и граница исправления

`None-stderr.log` — лог **тестового worker**, source9b6be2d/PID25200: в нём
`tokio-rt-worker ... has overflowed its stack`. Лог updater
`None-supervisor-stderr.log` содержит лишь unexpected EOF. Не путать эти два
процесса. Нет checkpoint01-baseline, новая controller activation ещё не выполнялась;
из failure нельзя делать вывод о качестве V5 network receiver или final commit.

MSVC assembly check `cargo rustc -p winbridge-worker --lib --target
x86_64-pc-windows-msvc --features update-validation -- --emit=asm` показал
1,268,096 bytes `.seh_stackalloc` у `update_control::validation::drive::poll`,
до вложенных control/serde calls. Wrapper attach::poll ещё148,304 bytes. Это
диагностическая цепочка всех стадий в одном debug future на обычном потоке Tokio.
Сама UpdatePreparationView8,280 bytes; расширение view увеличивает frame и у
старых baseline contracts, даже когда новое optional поле отсутствует.
Assembly — диагностическое объяснение; оно не заменяет Windows repeat.

Исправление только под `update-validation`: создавать/поллить весь fixture driver
на одном именованном thread со stack8MiB через **original runtime Handle**.
Возвращаемый JoinHandle join-ит owner; отдельный runtime, detached driver,
RUST_MIN_STACK, общие Tokio settings, новая попытка или продление window не нужны.
Original layout pin/Worker/registration и error→stop остаются в том же future.
Тесты проверяют отсутствие вызова factory без runtime и настоящий pipe+timer на
original IO с сохранением исходной ошибки после join. Добавить их native
selection в Main26 и независимый reader. Ordinary worker builds этого модуля не
содержат; установленный worker обновлять ради fixture fix не требуется.

Проверки исправления:2 tests passed на Debian (настоящий local pipe/timer,
no-runtime refusal), Linux и MSVC `cargo clippy -p winbridge-worker --lib --tests
--features update-validation --locked -- -D warnings` passed. fmt/diff и Python
syntax passed. Новый Main26 script требует те же2 tests на Windows; independent
reader их проверяет отдельно. Это ещё не успешный Main26.
