# ADR 0003 — локальная связь без шифрования

Accepted: 2026-10-04, прямое требование пользователя.

Продукт работает полностью локально между Windows host и Debian VM. Соединение не шифруется: использовать `ws://` на выбранном private VM adapter или loopback для local tests. TLS, certificates, VPN, SSH и public relays не входят в реализацию.

Соединение инициирует Windows worker. Настройки явно выбирают controller и локальную пару; instance/generation/version/capabilities нужны для корректного восстановления и сопоставления. Не обозначать nodeId как криптографическую идентичность.

Уточнение пользователя 2026-10-05: на этапе локальной разработки не блокировать входящие соединения по IP. Записывать источники активности в файл с ротацией; список разрешённых IP в конфигурации — возможное последующее расширение. Существующее поле allowedWorkerAddresses игнорируется для совместимости с локальными configs, новые examples его не содержат. Listener сохраняет выбранный адрес интерфейса, handshake пары остаётся обязательным.

Отмена TLS плана касается нового WinBridge. Netwatch с его внешними Debian VPS и прежними настройками не изменяется. Добавление encryption в будущем потребует новой пользовательской задачи, а не решения агента по старому proposal.
